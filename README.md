# FLIP THE WORLD — first playable prototype

This is a zero-cost HTML5 browser game prototype.

## Run it
Open `index.html` in a modern browser. On iPhone, the easiest way to test it is to publish the folder with GitHub Pages (instructions below).

## Publish free with GitHub Pages
1. Sign in at https://github.com/ and create a **public** repository named `flip-the-world`.
2. Choose **Add file → Upload files**.
3. Upload `index.html` from this folder and commit the changes.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for deployment. Your game URL will be `https://YOUR-USERNAME.github.io/flip-the-world/`.

## Game controls
Tap anywhere in the play area or use the FLIP GRAVITY button to switch between floor and ceiling. Avoid spikes and reach the portal. Five prototype levels are included.

## Important
This is an early prototype, not a finished commercial release. Before monetization or submitting to a platform, test thoroughly, improve level design/accessibility, add original art/audio, add privacy information if collecting data, and review the current platform policies and eligibility.
